Understanding Scale in Earth Engine

Three Types of Resolution

In remote sensing, "resolution" has three distinct meanings:

1. Spatial Resolution (Pixel Size)

The physical area on the ground represented by one pixel.

  • Landsat: 30 meters (roughly a baseball diamond infield)
  • Sentinel-2: 10-60 meters depending on band
  • MODIS: 250-1000 meters
  • Commercial (Maxar): 30 cm (can count cars)

2. Temporal Resolution (Revisit Time)

How often the satellite revisits the same location.

  • Landsat: Every 16 days
  • Sentinel-2: Every 5-10 days
  • Planet: Daily (using many small satellites)

3. Radiometric Resolution (Bit Depth)

The range of values a pixel can store.

  • 8-bit: 0-255 (older sensors)
  • 16-bit: 0-65,535 (modern sensors like Landsat 8)

Why Scale Matters in Earth Engine

⚠️ Critical Rule: In Earth Engine, scale is defined at the output. You must explicitly specify the scale, or Earth Engine will guess based on your zoom level!

This leads to two common issues:

  1. Statistics change as you zoom in/out if you don't specify scale
  2. Computations may fail if the scale produces too many pixels

Always Specify Scale

In reduceRegion()

// ❌ BAD: No scale specified - results will vary with zoom level
var badStats = image.reduceRegion({
  reducer: ee.Reducer.mean(),
  geometry: roi
});

// ✅ GOOD: Always specify scale
var goodStats = image.reduceRegion({
  reducer: ee.Reducer.mean(),
  geometry: roi,
  scale: 30  // meters - match Landsat's native resolution
});

In Exports

Export.image.toDrive({
  image: myImage,
  description: 'my_export',
  region: roi,
  scale: 30  // Always specify scale for exports!
});

Native Resolution

Each dataset has a "native" resolution - the scale at which it was originally captured. Using a different scale requires resampling:

  • Upsampling (finer scale): Creates more pixels from fewer - doesn't add real detail
  • Downsampling (coarser scale): Averages pixels together - loses detail but faster

Check native resolution in the Data Catalog or by printing the image:

var image = ee.Image('LANDSAT/LC08/C02/T1_L2/LC08_044034_20210101');
print('Projection:', image.projection());
print('Scale:', image.projection().nominalScale());

The Inspector and Zoom Level

When you click on the map with the Inspector tool, notice the scale displayed:

  • At zoom level 10: ~150 meters
  • At zoom level 12: ~40 meters
  • At zoom level 14: ~10 meters

This is the scale at which computations happen if you don't specify one. Always be explicit!

Handling "Too Many Pixels" Errors

If you get a "Computation timed out" or "maxPixels" error:

  1. Increase maxPixels: maxPixels: 1e9
  2. Use bestEffort: true for quick estimates
  3. Increase scale (coarser resolution)
var stats = image.reduceRegion({
  reducer: ee.Reducer.mean(),
  geometry: largeRegion,
  scale: 100,          // Coarser than native 30m
  maxPixels: 1e9,      // Allow more pixels
  bestEffort: true     // Auto-adjust if still too many
});

Key Takeaways

  • Scale is in meters in Earth Engine
  • Always specify scale in reduceRegion() and exports
  • Match scale to your data's native resolution when possible
  • Smaller scale = more detail = more pixels = longer computation
